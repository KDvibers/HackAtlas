# Fixtures

Все события вымышлены. `isDemo=true` и фиксация asOf=2026-10-12 обеспечивают воспроизводимость примеров. Даты обновлены для демонстрации будущих событий; это не изменение выбранного визуального стиля.

`catalog-page.json` — пример страницы для явного `sort=NEWEST`; порядок карточек предназначен для первого visual scenario (AI, Fintech, GameDev). По умолчанию API использует DEADLINE_ASC, поэтому DemoRepository должен уметь сортировать/фильтровать, а не выдавать этот неизменный список на любой запрос. publishedAt в dev seed задать в порядке, соответствующем NEWEST fixture.

`hackathon-detail.json` — подробно первый AI demo. Остальные detail примеры можно построить по той же схеме при реализации, сохранив IDs и явно demo-данные. `profile.json` — только demo account, его счётчики не значения новых реальных аккаунтов.

`manifest.json` сопоставляет файл и имя JSON Schema из OpenAPI. Форматная проверка этих файлов не заменяет integration tests настоящего сервера.

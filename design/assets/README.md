# Ассеты

## Текущее состояние M1 — 2026-10-12

Подготовлены четыре отдельных generated PNG, шесть файлов шрифтов, лицензии и образец типографики. Подробности и статус кандидатов: [REGISTRY.md](REGISTRY.md). Непроверенное и визуальные пробелы: [MISSING.md](MISSING.md). Ни один новый ресурс пока не объявлен утверждённым baseline.

## Исходные правила Starter

В комплекте нет готовой библиотеки игровых/AI иллюстраций или font files. Нужные мотивы перечислены в STYLE_LOCK. Не подменять их случайными картинками и не скрывать отсутствие ассетов.

Для каждого полученного ассета указать источник, лицензию/разрешение, назначение, статус placeholder/approved и наличие исходника. Не публиковать чужие логотипы/изображения автоматически. Секреты и личные фото пользователя не нужны для демо.

`MISSING.md` агент создаёт по фактическим пробелам. Лицензирование шрифта и glyph coverage проверить отдельно; точный шрифт изображения неизвестен.

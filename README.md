# HackAtlas — проектное задание

Мобильный каталог хакатонов для Android и iOS. Общий клиент на Kotlin Multiplatform + Compose Multiplatform; отдельный сервер на Java + Spring Boot.

**Состояние:** это стартовый комплект спецификаций и промптов для Codex, а не уже написанное, собирающееся или опубликованное приложение. Установочные файлы, Gradle/Maven wrapper, Java/Kotlin реализация и подключённый сервер здесь пока отсутствуют. Их необходимо создать по этапам.

Начните с [START_HERE.md](START_HERE.md).

| Ответственный | Область |
|---|---|
| Пользователь | `backend/`, `infra/`, серверный CI |
| Друг | `mobile/`, мобильные ресурсы и мобильный CI |
| Оба | `api/`, референс, общие продуктовые решения |

Рабочее название HackAtlas пока не означает регистрацию бренда или наличие GitHub-репозитория.

# Официальные источники для проверки toolchain

Подборка проверена 12 октября 2026. Это справочные источники, а не подтверждение сборки данного проекта. При начале работы сверить действующие версии и ограничения.

- Kotlin, совместимость: https://kotlinlang.org/docs/multiplatform/compose-compatibility-and-versioning.html
- Kotlin, FAQ и требования iOS: https://kotlinlang.org/docs/multiplatform/faq.html
- Kotlin, integration iOS: https://kotlinlang.org/docs/multiplatform/multiplatform-ios-integration-overview.html
- Ktor engines: https://ktor.io/docs/client-engines.html
- Multiplatform Settings (первичный репозиторий): https://github.com/russhwolf/multiplatform-settings
- Coil: https://coil-kt.github.io/coil/getting_started/
- Spring Boot system requirements: https://docs.spring.io/spring-boot/system-requirements.html
- Spring Security password storage: https://docs.spring.io/spring-security/reference/features/authentication/password-storage.html
- PostgreSQL version support: https://www.postgresql.org/support/versioning/
- GitHub CODEOWNERS: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners
- GitHub protected branches: https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches/about-protected-branches
- Android browser integration: https://developer.chrome.com/docs/android/custom-tabs
- Apple browser integration: https://developer.apple.com/documentation/safariservices/sfsafariviewcontroller

Имена, числа, события и суммы в fixtures являются проектными демонстрационными данными и не взяты из этих источников.

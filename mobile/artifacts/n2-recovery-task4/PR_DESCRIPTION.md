## Изменения

- Добавлен поток восстановления пароля для закрытого N2. Он открывается из
  «Забыли пароль?» и после `PASSWORD_RESET_REQUIRED` на экране входа.
- Запрос кода, проверка кода и установка нового пароля отправляются без
  `Authorization`. Токен сброса живёт в памяти до expiry и передаётся только
  в теле confirm. После `204` открывается обычный экран входа.
- Учтены TTL, общий `Retry-After` для verify/confirm, уход в фон и потерянные
  ответы. После неопределённого verify запрашивается новый код, после
  неопределённого confirm предлагается попробовать вход или начать
  восстановление заново.

## Проверка

- Прошли 317 unit-тестов, включая 11 новых сценариев.
- MockEngine проверил контракт, истечение grant и поздние ответы.
  TCP-тест Android подтвердил отсутствие повторной отправки verify и
  confirm при `503 Retry-After: 0`.
- Android debug и release собраны. Lint, валидатор API 0.1.1 и Gitleaks прошли.
- На Android API 36 с синтетическим сервером проверены
  `PASSWORD_RESET_REQUIRED`, сохранение challenge при возврате из фона
  и возврат к обычному входу после `204`.

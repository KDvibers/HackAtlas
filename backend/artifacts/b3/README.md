# Визуальная проверка B3

26 октября 2026, встроенный Chromium браузер Codex в Windows, отдельный собранный JAR в Ubuntu WSL2. PostgreSQL, учётная запись редактора и обращения были одноразовыми, созданными только для проверки. DEMO Clock: `2026-10-12T10:00:00Z`; реальные пользователи и события не затрагивались.

- [Вход](login.jpg): доступные подписанные поля и кнопка; пароль на screenshot не вводился.
- [Каталог](catalog.jpg): пять явно помеченных DEMO-событий; AI Sprint после сохранения имеет POSTPONED.
- [Редактор](editor.jpg): поля, даты, ссылки, независимые действия проверки/публикации и архива; полный screenshot страницы.
- [Очередь](queue.jpg): тестовые REPORT и SUGGESTION, свободный текст и ручная обработка.

В браузере выполнен вход редактора, выбран POSTPONED у AI Sprint и отправлена HTML-форма. Повторный HTTP GET подробностей подтвердил `eventStatus=POSTPONED` и `isDemo=true`. Проверены переходы каталог/редактор/очередь и выход. На широком desktop viewport поля и тексты не перекрываются. Native date/time controls отображают локаль браузера; отправляются стандартные ISO значения HTML input.

Автоматические HTTP-тесты отдельно проверяют CSRF, запрет USER, публикацию/архив, отзыв сессии, обновление saved, валидацию и ошибки БД. Эти screenshots не являются проверкой Android/iOS, мобильной адаптации админки или внешнего deployment.
